# NameSSH

Небольшой SSH-клиент для Windows на Python: поиск SSH-серверов в локальной сети, подключение по паролю или приватному ключу и интерактивная консоль. Подойдёт для ПК, Raspberry Pi, Orange Pi и других устройств **с включённым SSH-сервером**.

## Скачать и запустить

Скачайте `NameSSH.exe` из [Releases](https://github.com/1xcoding/namessh/releases) и запустите его в Windows. Python на компьютере при этом не нужен. Исполняемый файл не подписан цифровой подписью, поэтому Windows SmartScreen может показать предупреждение. Если релиза ещё нет, приложение можно собрать по инструкции ниже.

1. Подключите компьютер и целевое устройство к одной локальной сети. На целевом устройстве включите SSH и узнайте имя пользователя и пароль (или подготовьте приватный ключ).
2. Выберите сетевой интерфейс и нажмите **«Найти устройства»**. Поиск проверяет указанный порт (по умолчанию 22) и показывает только устройства, ответившие SSH-баннером. Выберите строку, чтобы подставить адрес. Адрес и порт также можно ввести вручную, в том числе для устройств вне локальной сети.
3. Введите пользователя и пароль и/или выберите файл приватного ключа. При зашифрованном ключе поле пароля используется также как пароль ключа. Нажмите **«Подключиться»**.
4. При первом подключении независимо сверьте показанный SHA256-отпечаток с сервером и подтвердите его только при совпадении. На Linux-сервере отпечатки можно посмотреть, например, командой `sudo ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub -E sha256` (файл должен соответствовать показанному типу ключа).
5. Щёлкните по терминалу и вводите команды. Для вставки используйте **Ctrl+Shift+V**; Ctrl+C отправляется удалённой программе. Кнопка «Отключиться» завершает сеанс.

## Особенности и безопасность

- Устройство может не обнаружиться, если SSH выключен, файрвол блокирует порт, включена изоляция Wi-Fi-клиентов, или устройство находится в другой подсети. Введите адрес вручную или проверьте настройки сети и SSH. Используйте поиск только в сетях, где вам разрешено это делать.
- Сети больше 1024 адресов автоматически ограничиваются локальной подсетью /24; остальные интерфейсы выбираются из списка. Сканируется только выбранный порт. VPN и виртуальные сетевые адаптеры тоже могут появиться в списке.
- SSH-баннер не позволяет надёжно определить модель оборудования: приложение не утверждает, что найдено именно Raspberry Pi или Orange Pi.
- Подтверждённые ключи хранятся отдельно от системного SSH в `%APPDATA%\NameSSH\known_hosts` (в Linux/macOS — `~/.config/NameSSH/known_hosts`, если `APPDATA` не задан). При изменении ключа подключение отклоняется. Если ключ действительно заменён, сначала проверьте новый отпечаток, затем удалите соответствующую строку из этого файла и подключитесь заново. Пароли и приватные ключи приложение не сохраняет.
- Терминал — базовая эмуляция xterm, фиксированный размер 120×32, без поддержки всех функций полноценных терминалов и без истории прокрутки; сложные TUI-программы могут работать неидеально. Поддерживаются обычные интерактивные команды и основные клавиши.

## Запуск из исходников

Нужны Python 3.10+ и Tkinter (в некоторых дистрибутивах Linux пакет `python3-tk` устанавливается отдельно).

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

## Сборка EXE в Windows

```powershell
python -m pip install -r requirements.txt pyinstaller
python -m unittest discover -s tests -v
python -m PyInstaller --noconfirm --clean --onefile --windowed --name NameSSH main.py
```

Результат: `dist/NameSSH.exe`. PyInstaller собирает Windows-приложение **на Windows**; сборка в Linux не создаёт Windows EXE. GitHub Actions также собирает EXE при отправке изменений в ветку и сохраняет его как артефакт `NameSSH-Windows`.
